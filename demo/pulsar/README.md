# Púlsar

Prototipo de juego de naves con scroll vertical, mejoras y puntuación
persistente.

## Estado

Prototipo 0.3 · bucle jugable completo. El control y el equilibrio de enemigos
siguen en ajuste.

## Controles

- Flechas o stick izquierdo para mover.
- Espacio o botón A para disparar.
- Escape para pausar.

## Estructura

- `src/game`: bucle, oleadas y colisiones.
- `src/ui`: menús y tabla de puntuación.
- `assets`: sonido y partículas provisionales.
