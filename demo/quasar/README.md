# Quásar

Pipeline de datos para consolidar métricas de varias fuentes en un almacén
único.

## Estado

En pausa desde septiembre. La extracción funciona; la transformación quedó a
medias y sin dueño.

## Componentes

- Conectores de dos fuentes con carga incremental.
- Esquema inicial del almacén.
- Tablero de control.
- Pruebas de calidad sobre los datos extraídos.
